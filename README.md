# 灯效工场

199 灯异形灯阵模拟与灯效编辑器，直接打开网站即可使用。

支持图层编排、火焰、冷白星流、滚动文字与多种预设；支持本地导入 INO / .h / 工程，以及算法、逐帧两种 RMT 导出。文件解析和灯效计算在浏览器内完成。工程只保存在当前浏览器，可使用“保存工程”导出后迁移到其他设备。

导出 ZIP 包含完整 ESP32 RMT 测试草稿、合入现有固件的效果头文件、接入代码及工程 JSON。默认沿用 199 灯、GPIO 18 和 GRB 顺序。接入已有固件使用 integration 文件夹并复用原驱动；独立草稿用于单独测试。

本仓库为网站运行文件，不包含个人工程和参考视频。目标控制器的编译占用与实时性能仍需实机验证。

导出器已在 Arduino-ESP32 2.0.17、3.3.11 的经典 ESP32 默认配置上验证四类完整草稿编译；另验证了店家原 RMT 示例的头文件接入。具体工程仍需按实际控制板及原固件配置编译、试灯。
